# MW Atelier — Menswear Store

React + Vite ecommerce demo inspired by the supplied editorial product-list reference.

## Features
- 16 supplied product images
- Responsive product grid, search, category filters and sorting
- Wishlist and persistent-in-session cart drawer
- Quantity controls and calculated totals
- Dummy Zimbabwe checkout: EcoCash, InnBucks, OneMoney, card, and cash on delivery
- Three.js interactive hero sculpture
- Responsive desktop/mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

> Payment controls are intentionally demonstrative. No real transaction or backend is connected.
